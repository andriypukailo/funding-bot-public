# 📘 Інструкція: як запустити бота фандінгу (для початківця)

Бот працює так: він напряму слухає біржі через WebSocket (миттєві дані),
рахує чистий прибуток, і коли до виплати фандінгу лишається ≤ 30 хв — шле
тобі повідомлення в Telegram. Працює 24/7 на хмарі, комп вмикати не треба.

Усе робиться **мишкою в браузері**. Нічого встановлювати на компʼютер не потрібно.

---

## ЧАСТИНА 1. Створюємо Telegram-бота (5 хвилин)

Це бот, від імені якого тобі приходитимуть сигнали.

1. Відкрий Telegram. У пошуку зверху напиши: **@BotFather** і відкрий його (з синьою галочкою).
2. Натисни **START** (або напиши `/start`).
3. Напиши команду: `/newbot`
4. Він спитає назву — напиши будь-яку, напр. `Мій Фандінг Бот`.
5. Потім спитає username — він має закінчуватись на `bot`, напр. `mij_funding_2024_bot`.
6. BotFather пришле тобі **токен** — довгий рядок типу:
   `7712345678:AAH4k9xZ...кучабукв...`
   👉 **СКОПІЮЙ його і збережи** (це твій `TELEGRAM_TOKEN`).

### Тепер дізнаємось твій CHAT_ID (куди слати сигнали):

7. У пошуку Telegram знайди **@userinfobot**, відкрий, натисни START.
8. Він одразу напише твій **Id** — число типу `123456789`.
   👉 Збережи його (це твій `TELEGRAM_CHAT_ID`).
9. ВАЖЛИВО: знайди свого новоствореного бота за username (крок 5) і натисни
   йому **START** — інакше він не зможе тобі писати.

✅ Тепер у тебе є два рядки: TELEGRAM_TOKEN і TELEGRAM_CHAT_ID.

---

## ЧАСТИНА 2. Кладемо код на GitHub (10 хвилин)

GitHub — безкоштовне місце для зберігання коду. Railway бере код звідти.

1. Зайди на **github.com**, натисни **Sign up**, зареєструйся (email + пароль).
2. Після входу натисни зелену кнопку **New** (створити репозиторій).
3. Назву (Repository name) впиши: `funding-bot`. Постав крапку **Public**.
   Натисни **Create repository**.
4. На наступній сторінці натисни посилання **uploading an existing file**
   ("завантажити наявні файли").
5. Перетягни сюди мишкою всі 4 файли з папки, яку я дав:
   - `package.json`
   - `config.js`
   - `index.js`
   - `README.md` (цей файл)
6. Внизу натисни зелену кнопку **Commit changes**.

✅ Код тепер на GitHub.

---

## ЧАСТИНА 3. Запускаємо на Railway (10 хвилин)

Railway — хмара, де бот працюватиме завжди.

1. Зайди на **railway.app**, натисни **Login** → **Login with GitHub**
   (увійди тим самим акаунтом GitHub).
2. Натисни **New Project** → **Deploy from GitHub repo**.
3. Дозволь Railway доступ до твого GitHub, обери репозиторій `funding-bot`.
4. Railway сам побачить, що це Node.js, і почне встановлення. Зачекай 1-2 хв.

### Тепер вписуємо секрети (токен Telegram):

5. У проєкті відкрий вкладку **Variables** (Змінні).
6. Натисни **New Variable** і додай ДВІ змінні (по черзі):
   - Назва: `TELEGRAM_TOKEN` → Значення: твій токен з Частини 1
   - Назва: `TELEGRAM_CHAT_ID` → Значення: твій id з Частини 1
7. Railway автоматично перезапустить бота.

### Перевірка:

8. Через хвилину тобі в Telegram має прийти:
   `🚀 FundingHunter запущено!`
9. Якщо хочеш бачити живі дані — у Railway відкрий вкладку **Settings** →
   **Generate Domain**. Зʼявиться посилання — відкрий його, побачиш таблицю
   з котируваннями (значить бот живий).

✅ ГОТОВО. Бот працює 24/7. Сигнали приходитимуть самі.

## ЯК ЗМІНИТИ НАЛАШТУВАННЯ ПІЗНІШЕ

Усі фільтри — у файлі **config.js**. Наприклад, хочеш чистий прибуток від 2%:
відкрий `config.js` на GitHub (олівець ✏️ зверху файлу), зміни
`MIN_NET_PROFIT: 1.0` на `MIN_NET_PROFIT: 2.0`, натисни **Commit changes**.
Railway сам підхопить зміну і перезапуститься.

Основні параметри:
- `MIN_NET_PROFIT` / `MAX_NET_PROFIT` — діапазон чистого прибутку (%)
- `FEE_PER_SIDE` — твоя комісія за одну сторону угоди (%)
- `MAX_PRICE_CHANGE_24H` — макс. рух ціни за 24г (%)
- `MIN_VOLUME_24H` / `MIN_OI` — мінімальна ліквідність ($)
- `SIGNAL_WINDOW_MIN` — за скільки хвилин до виплати слати сигнал
- `RESEND_COOLDOWN_MIN` — щоб не спамити одним сигналом

## ВАЖЛИВО ЗНАТИ

- **Фандінг є лише на фʼючерсах.** Спот його не платить. Сигнал каже,
  що робити на фʼючерсах і що — на споті (щоб прибрати ціновий ризик).
- **Бот показує лише пари, що є і на споті, і на фʼючерсах.** При старті
  бот робить REST-запит до кожної біржі й завантажує ТОЧНІ списки спотових
  ринків — тож перевірка справжня, не приблизна. Списки оновлюються кожні 12 год.
- **Інтервали фандінгу 1–8 год беруться з біржі для кожної пари окремо.**
  Бот не вгадує — він читає реальний інтервал (Binance/Bybit/Bitget/Gate через
  REST, OKX вираховує з часу наступної виплати). У сигналі видно «кожні Nг».
- **Це не фінансова порада.** Бот лише знаходить можливості за твоїми
  фільтрами. Рішення про угоду — за тобою. Враховуй комісії, прослизання
  ціни, ризик розширення спреду і можливу затримку виведення коштів.
- Railway дає безкоштовний стартовий кредит; далі ~5$/міс за постійну роботу.

## ЯКЩО ЩОСЬ НЕ ПРАЦЮЄ

- Не прийшло привітання → перевір, що натиснув START своєму боту (Частина 1, крок 9)
  і що TELEGRAM_TOKEN/CHAT_ID вписані без пробілів.
- У Railway вкладка **Deployments** → **View Logs** показує, що відбувається.
  Шукай рядки `🔌 ... підключено` — значить біржі підʼєдналися.
- Біржа може тимчасово не віддавати дані — бот сам перепідключиться через 5 сек.
